## 🚀 Featured Projects

### 🛒 [Olist E-Commerce Sales Analytics](https://github.com/Devraj-prasad07/olist-end-to-end-data-analytics)

**Python • PostgreSQL • Power BI • DAX**

An end-to-end e-commerce analytics project using the Brazilian Olist dataset to analyze sales performance, customer behavior, product performance, and revenue trends.

**Key highlights:**

- 🔄 Built a Python-based ETL pipeline for data extraction, transformation, and loading
- 🧹 Cleaned and transformed raw transactional data
- 🗄️ Designed an analytical data model in PostgreSQL
- 📅 Created a dedicated Calendar table for time-based analysis
- 📊 Developed interactive Power BI dashboards
- 🧮 Created DAX measures for business KPIs
- 📈 Analyzed revenue, orders, customers, products, and regional performance

---

### 👥 [Customer Segmentation & RFM Revenue Optimization](https://github.com/Devraj-prasad07/RFM-Customer-Segmentation)

**Python • PostgreSQL • Power BI • DAX**

A customer analytics project using the **Online Retail II** dataset to understand purchasing behavior and identify high-value and at-risk customer segments.

**Key highlights:**

- 🧹 Cleaned and prepared **779K+ transaction records**
- 📅 Calculated customer **Recency**
- 🔢 Calculated purchase **Frequency**
- 💰 Calculated customer **Monetary Value**
- 🧮 Developed an RFM scoring framework
- 👥 Segmented customers based on purchasing behavior
- 🎯 Identified **Champions, Loyal Customers, Potential Loyalists, At Risk, and Hibernating** customers
- 📊 Built Power BI visualizations for customer and revenue analysis
